# Marsya Portfolio

Personal portfolio built with React and Vite. Warm beige visual direction.

## Run locally

```bash
npm install
npm run dev
```

## Add your profile photo

Put your image in `public/` and name it `profile.png`.
The hero section already references `/profile.png`. If the image is missing, a monogram placeholder is shown.

## Personalize before publishing

- Replace `emailkamu@example.com` in `src/main.jsx` with your active email.
- Review project and experience descriptions to make sure every detail is accurate.
- Add GitHub and LinkedIn links if you want them displayed.
- Change the page title and description in `index.html` if needed.

## Build

```bash
npm run build
```

The production output is generated in `dist/`.
